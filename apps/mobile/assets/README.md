# Assets klasörü

Expo uygulamasının statik görselleri burada olacak:

- `icon.png` — uygulama ikonu (1024x1024)
- `splash.png` — splash ekranı (1284x2778)
- `adaptive-icon.png` — Android adaptive icon (1024x1024)
- `favicon.png` — web favicon

Faz 2'de logo ve görseller eklenecek.

Bu klasörü `.gitkeep` ile boş tutmak için aşağıdaki komutu çalıştırın:
```
touch .gitkeep
```

Veya bu README'yi koruyabilirsiniz.
